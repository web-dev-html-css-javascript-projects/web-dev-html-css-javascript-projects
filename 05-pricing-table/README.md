# SaaS Pricing Matrix Table

## Overview
A feature comparison pricing table designed to display subscription tiers clearly.

## What I Practiced
- Clean HTML table structure (`<thead>`, `<tbody>`, `<th>`, `<td>`).
- Highlighting a specific column (Standard/Popular plan) with subtle background tint and badge.
- Horizontal scroll wrapper (`overflow-x: auto`) so the table stays readable on mobile without breaking.

## Files
- `pricing-table.html`: Table markup.
- `style.css`: Table styling and responsive scroll wrapper.

## How to View
Open `pricing-table.html` in your browser.
