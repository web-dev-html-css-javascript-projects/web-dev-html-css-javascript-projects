# Tech Blog Post Layout

## Overview
An editorial blog post layout with an article area, custom quote styling, and a sidebar for related topics.

## What I Practiced
- 2-column editorial layout using flexbox (main article + sidebar).
- Semantic tags: `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<blockquote>`, `<cite>`, and `<code>`.
- Mobile responsive stacking for smaller screen sizes.

## Files
- `blog-page.html`: Blog article structure.
- `style.css`: Typography, quote, code snippet, and sidebar styles.

## How to View
Open `blog-page.html` in your browser.
