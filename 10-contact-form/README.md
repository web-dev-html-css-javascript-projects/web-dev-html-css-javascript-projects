# Contact Us Form

## Overview
A comprehensive contact form with clean input groups, topic grouping, file attachment, and character limits.

## What I Practiced
- Input groups with vertical label alignment for clean readability.
- Dropdown select with grouped options using `<optgroup>`.
- Interest checkboxes and radio buttons.
- Form validation attributes (`required`, `minlength`, `maxlength`).

## Files
- `contact-form.html`: Form structure.
- `style.css`: Input styling, focus states, and button styles.

## How to View
Open `contact-form.html` in your browser.
