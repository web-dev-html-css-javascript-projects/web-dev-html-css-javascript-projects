# Contact Form

## 📌 Objective

Build a professional contact form using HTML5 that demonstrates different form controls and validation techniques.

---

## 📚 Concepts Covered

- HTML Forms
- Labels
- Input Types
- Textarea
- Select
- Option
- Optgroup
- Fieldset
- Legend
- Button
- HTML5 Validation
- Accessibility

---

## 🎯 Learning Outcomes

After completing this task, you will be able to:

- Create accessible forms.
- Use different input types correctly.
- Apply built-in HTML validation.
- Organize forms using fieldsets.
- Improve user experience with placeholders and autocomplete.

---

## 💡 Interview Questions

1. What is the purpose of `<label>`?
2. Why should labels be associated with inputs?
3. Difference between `readonly` and `disabled`?
4. Difference between `placeholder` and `value`?
5. What is the purpose of `required`?
6. What is `autocomplete`?
7. Difference between radio buttons and checkboxes?
8. Why do we use `<fieldset>` and `<legend>`?
9. Difference between `<button>` and `<input type="submit">`?
10. What is the purpose of the `pattern` attribute?
