# FAQ Page

## 📌 Objective

Build a Frequently Asked Questions (FAQ) page using semantic HTML5.

---

## 📚 Concepts Covered

- Semantic HTML
- `<details>`
- `<summary>`
- Headings
- Paragraphs
- Lists
- Links
- Accessibility

---

## 🎯 Learning Outcomes

After completing this task, you will be able to:

- Create collapsible FAQ sections.
- Use native HTML interactive elements.
- Improve accessibility without JavaScript.
- Structure information clearly.

---

## 💡 Interview Questions

- What is the `<details>` element?
- What is the purpose of `<summary>`?
- Can `<details>` work without JavaScript?
- Why are `<details>` and `<summary>` better than creating custom accordions?
