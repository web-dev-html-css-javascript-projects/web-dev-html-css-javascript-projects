Frequently Asked Questions

Common HTML interview questions and answers

1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to structure content on web pages.

2. What is semantic HTML?

Semantic HTML uses meaningful elements like <header>, <main>, <article>, and <footer> to describe the purpose of content, helping search engines and screen readers understand the page structure.

3. What is the difference between id and class?

An id uniquely identifies a single element on a page, while a class can be shared by multiple elements to apply the same styling.

4. What is the difference between <div> and <span>?

A <div> is a block-level element (takes up full width and starts on a new line), while a <span> is an inline element (only takes up as much space as its content and does not start a new line).

5. What is the DOM?

The DOM (Document Object Model) is a tree-like representation of an HTML document that allows programming languages like JavaScript to access and modify elements dynamically.

6. Why do we use forms?

Forms are used to collect user input (like text inputs, select dropdowns, checkboxes) and send that data to a server for processing or storage.
