Common HTML interview questions and answers

1. What is HTML?

HTML (HyperText marku lanaguge) is the standard markup langauge used to structure content on web pages

2. What is semantic HTML?

Semantic HTML uses meaningful elements like <header>, <main>, <article>, and <footer> to describe the purpose of content.

3.What is the difference between id and class?

An id uniquely identifies one element, while a class can be shared by multiple elements.

5. What is the DOM?

The DOM (Document Object Model) is a tree-like representation of an HTML document that allows JavaScript to access and manipulate elements.
