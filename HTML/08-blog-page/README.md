# Blog Page

## 📌 Objective

Build a semantic blog page using HTML5 that demonstrates proper document structure, accessibility, and SEO-friendly markup.

---

## 📚 Concepts Covered

- HTML5 Semantic Elements
- `<header>`
- `<nav>`
- `<main>`
- `<article>`
- `<section>`
- `<aside>`
- `<figure>`
- `<figcaption>`
- `<time>`
- `<blockquote>`
- `<cite>`
- `<address>`
- Images
- Hyperlinks
- Accessibility
- SEO Meta Tags

---

## 🎯 Learning Outcomes

After completing this task, you will be able to:

- Build a complete blog page using semantic HTML.
- Organize content using semantic elements.
- Display publication dates with the `<time>` element.
- Add images with captions using `<figure>` and `<figcaption>`.
- Display quotations using `<blockquote>`.
- Cite sources using `<cite>`.
- Add author contact information using `<address>`.
- Improve accessibility and SEO with semantic HTML.

## 📖 Key HTML Elements Used

| Element | Purpose |
|---------|---------|
| `<article>` | Represents an independent blog post or article |
| `<section>` | Groups related content |
| `<aside>` | Contains related or supplementary information |
| `<figure>` | Groups media with a caption |
| `<figcaption>` | Provides a caption for media |
| `<time>` | Represents dates and times |
| `<blockquote>` | Displays a long quotation |
| `<cite>` | References the source of a creative work |
| `<address>` | Displays contact information |
