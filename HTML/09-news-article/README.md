# News Article

## 📌 Objective

Build a professional news article webpage using semantic HTML5. This project focuses on structuring news content while practicing semantic elements and text formatting tags.

---

## 📚 Concepts Covered

- Semantic HTML5
- `<header>`
- `<main>`
- `<article>`
- `<section>`
- `<footer>`
- `<figure>`
- `<figcaption>`
- `<time>`
- `<mark>`
- `<abbr>`
- `<small>`
- `<ins>`
- `<del>`
- `<sup>`
- `<sub>`
- Images
- Hyperlinks
- Accessibility
- SEO Basics

---

## 🎯 Learning Outcomes

After completing this task, you will be able to:

- Build a semantic news article webpage.
- Organize content using HTML5 semantic elements.
- Highlight important information using `<mark>`.
- Display abbreviations using `<abbr>`.
- Show inserted and deleted content using `<ins>` and `<del>`.
- Display scientific and mathematical expressions using `<sub>` and `<sup>`.
- Improve accessibility and SEO using semantic HTML.

## 📖 Key HTML Elements Used

| Element | Purpose |
|----------|---------|
| `<article>` | Represents a self-contained news article |
| `<section>` | Groups related content |
| `<figure>` | Groups media content |
| `<figcaption>` | Adds a caption to media |
| `<time>` | Represents dates and times |
| `<mark>` | Highlights important text |
| `<abbr>` | Defines abbreviations with their full meaning |
| `<small>` | Displays secondary or fine-print text |
| `<ins>` | Represents inserted content |
| `<del>` | Represents deleted content |
| `<sup>` | Displays superscript text |
| `<sub>` | Displays subscript text |
