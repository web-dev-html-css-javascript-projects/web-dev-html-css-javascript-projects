# Personal Portfolio Website

## 📌 Objective

Build a complete personal portfolio website using only HTML5. This project combines all HTML concepts learned throughout the HTML module and serves as the final project.

## 🎯 Learning Outcomes

After completing this project, you will be able to:

- Build a complete multi-section portfolio.
- Apply semantic HTML5 correctly.
- Organize content professionally.
- Embed multimedia.
- Create accessible forms.
- Structure pages for SEO.
- Follow HTML best practices.
