# Pricing Table

## 📌 Objective

Build a responsive-ready pricing table using semantic HTML5. The goal is to present different pricing plans in a clear and organized format using HTML only.

---

## 📚 Concepts Covered

- Semantic HTML5
- Tables
- `<table>`
- `<thead>`
- `<tbody>`
- `<tfoot>`
- `<tr>`
- `<th>`
- `<td>`
- Headings
- Paragraphs
- Lists
- Buttons
- Links
- Accessibility

---

## 🎯 Learning Outcomes

After completing this task, you will be able to:

- Create well-structured HTML tables.
- Display pricing plans using semantic HTML.
- Organize tabular data correctly.
- Differentiate between table headers and table data.
- Build clean and readable layouts for comparison tables.

---

## 💡 Interview Questions

- What is the difference between `<th>` and `<td>`?
- What is the purpose of `<thead>`, `<tbody>`, and `<tfoot>`?
- When should tables be used in HTML?
- Why should tables not be used for page layout?
- What are `rowspan` and `colspan`?
