# Interactive FAQ Accordion

## Overview
A lightweight FAQ accordion page built using native HTML5 `<details>` and `<summary>` tags without needing any JavaScript.

## What I Practiced
- Utilizing browser-native collapse/expand functionality with `<details>`.
- Custom styling for open state using `details[open]`.
- Subtle hover animations and clean border separators.

## Files
- `faq.html`: FAQ questions and answers.
- `style.css`: Accordion card styling.

## How to View
Open `faq.html` in your browser and click on any question to expand it.
