# Modern Login Form Card

## Overview
A centered authentication card created to practice form layout, input styling, focus states, and clean spacing.

## What I Practiced
- Proper form input associations (`label for` and `input id`).
- Focus rings and hover states for better user feedback.
- Simple centered layout using flexbox on the body.

## Files
- `login.html`: Login form markup.
- `style.css`: Form styling and gradient background.

## How to View
Open `login.html` in your browser.
